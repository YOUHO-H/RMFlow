# RMFlow

This repository contains the implementation for the paper **“RMFLOW: Refined Mean Flow by a Noise-Injection Step for Multimodal Generation.”**

Paper: [arXiv:2602.00849](https://arxiv.org/abs/2602.00849)

To run the code for a specific task, navigate to the corresponding folder and execute:

```bash
chmod +x run.sh
./run.sh
```
